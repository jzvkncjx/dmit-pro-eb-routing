# DMIT 三网优化：Pro 和 EB 线路怎么选？洛杉矶、香港、东京全套餐价格与避坑清单

搜「DMIT 三网优化」的人，大多已经过了"要不要买"这个阶段。主机圈管 DMIT 叫"大妈"，知道它家的 CN2 GIA 在美西有货、知道它有几个机房，真正卡住的地方是另一件事：DMIT 的产品线里只有两条算三网优化，套餐名字又长得像密码，Pro、EB、T1 三组字母看完还是不知道该点哪个。

更麻烦的是，你随手翻到的攻略里，同一个套餐能出现三个价格。因为 AN4 平台下架、AN5 重新上架这轮变动之后，很多文章还停在旧价上。

这篇把三件事讲清楚：三网优化在 DMIT 这里具体指什么、三个机房的三网优化套餐现在卖多少钱、以及按你自己的宽带运营商该怎么挑。

## 先说结论：DMIT 的三条网络，只有两条是「三网优化」

DMIT 把 VPS 按回程线路分成三个系列，这个划分比机房更影响体验：

- **Tier 1（T1 / Standard）**：国际 BGP 线路，接了 Telia、Zayo、Cogent 这类国际上游，价格最低、带宽最大、流量最多。它对中国大陆不做定向优化。
- **Premium（Pro）**：以电信 CN2 GIA 为核心的精品线路组合。
- **Eyeball（EB）**：以移动 CMIN2 为核心，联通和电信走 AS9929 / AS58807 一侧。

把 T1 当三网优化买，是新手最容易踩的坑。它的页面同样写着 10Gbps、同样在大流量套餐里排前面，但电信用户的实际体验可能比部分美西普通线路还差。

### Pro 和 EB 的路由差在哪

洛杉矶 Pro 系列（LAX.AN5.Pro）的路由是这样走的：电信去程走 GIA（AS4809），联通去程直连 AS4837，移动去程经香港移动 AS58453 进洛杉矶；**三网回程统一走 GIA（AS4809）**。回程统一这一点比去程更重要，因为多数人感受到的卡顿来自下行。

洛杉矶 EB 系列（LAX.AN5.EB）的回程是三网 CMIN2：电信在 AS9929 和 AS58807 之间做负载均衡，联通走 AS9929，移动走 AS58807。联通和移动用户在这条线上的性价比通常比 Pro 更高。

香港 Pro（HKG.AN5.Pro）是三网回程经香港 CTG 接入国内 CN2 GIA，电信去程直接 CN2 GIA 连到香港 CTG，联通走 AS4837 + AS10099，移动走香港 CMI。香港的物理距离摆在那里，这三条线加起来，第三方 Ping 数据大致落在 40–50ms 区间，是全国三网都比较平均的一档。

东京 Pro（TYO.AS3.Pro）走 CN2 GIA / 10099（9929）/ CMI 组合，测试 IP 是 154.12.190.32。

有一个细节值得单独提一下：有第三方记录称 Pro 系列的 IPv6 回程实际走的是 CMIN2，走 CN2 GIA 的是 IPv4。如果你业务重度依赖 IPv6，别只看 IPv4 的 traceroute 就下单。DMIT 官方的 Looking Glass 按机房分开，下单前自己跑一遍最省事。

## 按你的宽带运营商挑，比按机房挑更管用

**电信用户**：优先 Pro。CN2 GIA 本来就是电信自己的高端产品线，电信去程走 AS4809 是这条线路成本最高、也最稳的部分。EB 系列对电信只是"能用的 AS9929/58807 均衡"，不在一个档。

**联通用户**：Pro 和 EB 都行。EB 的联通回程明确走 AS9929，这是联通自己的精品网，价格却按 EB 计。同样预算下，EB 的配置更高，联通用起来不吃亏。

**移动用户**：优先看 EB。移动在 EB 上走 AS58807（CMIN2），本来就是移动的国际优质出口；EB 给到的流量还更多。除非你确实遇到 CMIN2 段晚高峰波动，才需要考虑加钱上 Pro。

**预算敏感但要国内速度**：洛杉矶 Pro 的 TINY / Pocket 是这条线里最便宜的门票，缺点是流量小、端口低。跑个人站点、几个自动化脚本、轻量代理基本够。

**建站且用户在国内**：香港 Pro。40–50ms 的三网平均延迟是洛杉矶换不来的，代价是流量贵、超量政策也更紧。

**延迟敏感的接口和后台**：东京 Pro。

需要提醒一句：DMIT 的价格不是一直往下走的。AN4 下架、AN5 上线那轮，入门档月付从 $9.99 涨到 $12.98 左右，最低计费周期也从月付改成季付。所以看到半年前攻略里"$9.99 起"的说法，不必怀疑自己找错了地方，那批资源已经不卖了。

## 优惠码、付款和几个容易忽略的条款

DMIT 的优惠码时效性很强，活动季一过就失效，而且大多限定了产品线和付款周期。第三方整理里出现频率比较高、相对值得先试的几条是：

- `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF`：洛杉矶 EB 系列非月付，循环折扣。
- `Lite-Annually-Recur-30OFF`：被称为 Lite / Standard 网络系列的年付折扣。
- `Lite-Semi-Annually-Recur-20OFF`：同系列的半年付折扣。
- `202510_HKG_TYO_PRO_20OFF_RECURRING`：香港 / 东京 Pro 系列，季付及更长周期。

用法都一样：选好套餐和付款周期，在结算页填入优惠码点 Validate 验证。优惠码和套餐对不上就是无效，别硬试。这些码来自第三方汇总，官方并没有承诺长期有效，下单前务必自己验一次。

付款方式支持支付宝、PayPal 和信用卡，国内用户不需要折腾外币卡。也有资料提到微信支付，实际选项以下单页面为准。

两个常被忽略的条款值得一提。一是 IP 被墙的处理：第三方整理的说法是每 15 天可以免费换一次 IP，其他情况换 IP 收 5 美元。做代理的用户基本把这条当作核心保障来看，但它属于商家政策，随时可能调整。二是退款：第三方整理的规则是购买 3 天内且流量使用不超过 30GB 可全额退（扣支付网关手续费），30 天内可按剩余价值部分退；而"网络不够好""IP 地理位置原因"明确列在不退款的情形里。也就是说，觉得线路不合预期，最好不要靠退款兜底，先测试再长期付款更实际。

## 常见问题

**三网优化是不是等于不丢包、不卡？**
不是。三网优化解决的是路由走哪条骨干网的问题，晚高峰的拥塞、你本地宽带到出口的那一段，都不在商家控制范围内。用官方 Looking Glass 拿自己所在地跑一遍，比看任何测评都准。

**T1 能不能当三网优化用？**
不能。它接的是国际上游，对中国方向没有优化。香港 T1 尤其要注意，电信用户买它可能得到比美西还高的延迟。

**AN4、AS3、AN5 是什么？**
是服务器硬件平台代号。AN5 是 AMD EPYC 9005 系列，AS3 是 EPYC 7003 系列，AN4 是 EPYC 9004 系列。洛杉矶的 AN4 已经下架，AN5 是当前主力；东京 Pro 目前还在 AS3 上。平台代号影响算力和磁盘性能，不影响线路类型。

**为什么同一款套餐在不同文章里价格不一样？**
因为 DMIT 调整过价格，很多文章停在旧数据上。判断新旧有个简单办法：写着 AN4、$9.99/月起、或者"优惠码 2025"开头的，基本都是上一轮的资料。

**流量跑超了会怎样？**
洛杉矶 Pro、EB 和 T1 都是限速后继续跑，Pro / EB 按套餐档位降到 4–10Mbps，T1 大流量档能保持 100–500Mbps，不会直接断网。东京 Pro 的做法不同，超量后会暂停，跑大流量的场景要留意。
